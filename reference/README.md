# reference/ (git-ignored)

Put local copies of reference material here: the MOE romanisation manual and workbook, textbook PDFs, files downloaded
from data.gov.tw (`reference/gov/`). Nothing in this folder except this README is committed. The catalogue of what
exists and under which licence is `docs/sources.md`.

Copyrighted material you want on several machines (Glossika, textbooks) goes in the private repo `Hkka-private`,
not here.
